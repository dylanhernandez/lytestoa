# LyteStoa
A fast, responsive Hugo theme purpose-built for curating, showcasing, and embedding playable HTML5 game galleries.

## Status

🚧 **Work in Progress** — Initial project scaffold.

## Planned Features

- **Responsive Gallery Grid:** Clean card layouts with cover art, tags, and previews.
- **Playable Game Stage:** Dedicated single-page templates with responsive containers, aspect-ratio locking, and fullscreen toggles.
- **Zero-Bloat Performance:** Minimal CSS and vanilla JS so the browser's resources stay focused on running the games.
